# Contributing

Thanks for contributing to Refactored Winner.

## Development

1. Fork the repository.
2. Create a feature branch.
3. Make focused changes with tests where appropriate.
4. Run the project's checks locally.
5. Open a pull request with a clear description of the change.

## Commit Messages

Use concise, descriptive commit messages. Prefer imperative language and keep unrelated changes in separate commits.

## Pull Requests

Please explain what changed, why it changed, and how the change was tested.
